## 🏗️ Architecture & Modularity
This project is built using a 100% cloud-based, modular software pipeline to accommodate simultaneous development across a 12-hour time difference:
1. `data_ingestion()` - Prepares and normalizes input data.
2. `problem_formulation()` - Translates the sustainability problem into a mathematical operator (QUBO, Hamiltonian, or Feature Map).
3. `build_quantum_circuit()` - Compiles the parameterized variational quantum circuit.
4. `execute_and_optimize()` - Runs the simulation via cloud-accelerated backends and optimizes parameters.
